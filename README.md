# 🗺️ The Lost Treasure – Python Adventure Game

A simple text-based adventure game built using Python, where players explore a mysterious forest or cave in search of a legendary treasure.

## 🎮 About the Game

Players enter their name and choose between two adventure paths:

- **Dark Forest:** Follow a river or climb a tree.
- **Mysterious Cave:** Light a torch or proceed in the dark.

Every decision leads to a different outcome. Players can win, lose, or restart the adventure and try again.

## ✨ Features

- Interactive text-based gameplay
- Player name input
- Multiple adventure paths
- Different winning and losing outcomes
- Restart option to play again

## 🛠️ Concepts Used

- Python variables
- User input and output
- Conditional statements (`if`, `elif`, `else`)
- Loops (`while`)
- Functions
- String methods

## 🚀 How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

```bash
python adventure_game.py
```
